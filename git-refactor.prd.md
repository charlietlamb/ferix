# Git Refactor PRD: Push & PR Integration

## Overview

Integrate the existing `--push` and `--pr` CLI flags into the orchestrator completion flow. The flags are already defined in the CLI and config schema but are not consumed by the orchestrator.

## Current State

### What Exists
- **CLI flags** (`apps/code/src/index.ts:16-17`):
  ```typescript
  .option("--push", "Push branch after completion")
  .option("--pr", "Create PR after pushing")
  ```
- **Config schema** (`apps/code/src/domain/schemas/config.ts:33-34`):
  ```typescript
  push: S.optional(S.Boolean),
  pr: S.optional(S.Boolean),
  ```
- **Git service methods** (`apps/code/src/layers/git/file-system.ts`):
  - `pushBranch(sessionId)` - executes `git push -u origin ferix/{sessionId}`
  - `createPR(sessionId, title, body)` - executes `gh pr create --title "..." --body "..."`

### What's Missing
- No code calls `git.pushBranch()` or `git.createPR()` based on config flags
- No domain events for push/PR operations
- No PR title/body generation from session context

### 4. Implement Git Operations in Completion Stream

**File:** `apps/code/src/orchestrator/loop.ts`

Inside `createCompletionStream`, after the final commit and before building the summary:

```typescript
// Push branch if config.push is true
let branchPushed = false;
if (config.push === true) {
  yield* git.pushBranch(session.id).pipe(
    Effect.tap(() => Effect.sync(() => { branchPushed = true; })),
    Effect.tapError((error) =>
      Effect.logDebug("Push failed, continuing", {
        sessionId: session.id,
        error: String(error),
      })
    ),
    Effect.orElseSucceed(() => undefined)
  );
}

// Create PR if config.pr is true (requires push first)
let prUrl: string | undefined;
if (config.pr === true && branchPushed) {
  const title = `feat: ${session.task.slice(0, 50)}`;
  const body = buildPRBody(session, config);

  yield* git.createPR(session.id, title, body).pipe(
    Effect.tap((url) => Effect.sync(() => { prUrl = url; })),
    Effect.tapError((error) =>
      Effect.logDebug("PR creation failed, continuing", {
        sessionId: session.id,
        error: String(error),
      })
    ),
    Effect.orElseSucceed(() => undefined)
  );
}
```

### 5. Add PR Body Builder Helper

**File:** `apps/code/src/orchestrator/loop.ts`

Add helper function to generate PR body from session context:

```typescript
function buildPRBody(session: Session, config: LoopConfig): string {
  const completedTasks = session.completedTasks.length > 0
    ? session.completedTasks.map(t => `- ${t}`).join("\n")
    : "- No specific tasks tracked";

  return `## Summary
${config.task}

## Completed Tasks
${completedTasks}

---
Generated by Ferix`;
}
```

## Behavior

| Flags | Behavior |
|-------|----------|
| Neither `--push` nor `--pr` | No git operations after completion (current behavior) |
| `--push` only | Push branch to origin after final commit |
| `--pr` only | No-op (PR requires push first) |
| `--push --pr` | Push branch, then create PR with generated title/body |
